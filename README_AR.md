# صندوق شركة عزم الشرق

برنامج صندوق مستقل لشركة عزم الشرق.

## الوظائف
- زر كبير **إدخال أموال**
- زر كبير **خروج أموال**
- عرض الرصيد الحالي بالدولار USD
- عرض الرصيد الحالي بالدينار العراقي IQD
- تاريخ اليوم على الواجهة
- إدخال المبلغ والعملة واسم الشخص والزبون والتاريخ والملاحظات
- خروج المبلغ والعملة والجهة والمستلم والتاريخ والملاحظات
- حذف أي عملية
- حركة الصندوق من تاريخ إلى تاريخ
- إجمالي الإدخال والخروج لكل عملة ضمن الفترة
- كشف حساب PDF
- قاعدة بيانات SQLite
- واجهة موبايل
- PWA: يمكن تثبيته من المتصفح على الشاشة الرئيسية بعد نشره على HTTPS

## تشغيل على الكمبيوتر
1. ثبّت Python 3.11 أو أحدث.
2. افتح Terminal داخل المجلد.
3. نفّذ:
   pip install -r requirements.txt
4. ثم:
   python app.py
5. افتح:
   http://127.0.0.1:8501

## النشر
الحزمة تحتوي `render.yaml` و `Dockerfile`.
يمكن رفع المشروع على GitHub ثم نشره على خدمة تدعم Python/Docker وHTTPS.

### قاعدة البيانات الدائمة
استخدم متغير البيئة:
`AZM_CASHBOX_DB`

مثلاً:
`/var/data/azm_cashbox.db`

مهم: إذا كانت منصة الاستضافة لا توفر قرصاً دائماً، قد تُفقد بيانات SQLite عند إعادة النشر. لذلك استخدم Persistent Disk أو Volume.

## تثبيته كتطبيق على الهاتف
بعد نشره على رابط HTTPS:
- Android/Chrome: افتح القائمة واختر **Install app / إضافة إلى الشاشة الرئيسية**.
- iPhone/Safari: Share ثم **Add to Home Screen**.

سيظهر كبرنامج مستقل باسم **صندوق شركة عزم الشرق**.
