# صندوق عزم الشرق - النسخة النهائية

## أول دخول
اسم المستخدم: `admin`
الرقم السري: `Azm@2026`

غيّر الرقم السري مباشرة من صفحة المستخدمين.

## الصلاحيات
- ADMIN: كل شيء + إدارة المستخدمين.
- FULL: كل عمليات الصندوق والتقارير، بدون إدارة المستخدمين.
- VIEW: مشاهدة الحركة والأرصدة والتقارير وPDF فقط.

## مهم جداً للإنتاج
قاعدة SQLite تحتاج Persistent Disk/Volume حتى لا تضيع البيانات عند إعادة النشر.
اضبط `AZM_CASHBOX_DB` إلى مسار القرص الدائم، مثلاً `/var/data/azm_cashbox.db`.
